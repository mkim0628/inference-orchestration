1. **수학적 런타임 오류 경계 보장 (Activity C 24사이클 최초)**: 이중 항 오류 분해(δ_attn_bound + δ_value_bound) + 다단계 폴백 사다리(Level 0 INT8K+INT4V / Level 1 INT8K+FP16V / Level 2 FP16K+FP16V). error_bound ≥ actual_error 100/100 위반 0건. accuracy-preserving을 경험적 검증에서 수학적 런타임 보장으로 격상.
2. **위치 편향 크기 연속값 측정 기반 3단계 선택적 재인코딩 (Activity B 최초)**: ΔPos = |pos_target_start - pos_orig_start| / max_context_length로 직접 재사용(≤0.15) / 부분 재인코딩(0.15~0.40) / 전체 재인코딩(>0.40) 3단계 구분. 이분법적 설계 한계 극복.
3. **인증형 증류 압축 폐루프 파이프라인 (Cross-1 최초)**: RuntimeCertified 오류 경계가 KVSculpt 증류 압축 품질을 실시간 검증하는 "압축 + 인증 + 온라인 예산 적응" 통합 구조.

## 설계 관찰 및 유의사항

1. **error_threshold=0.005 보수성**: 임의 분포 텐서에서 ~96% 요청이 Level 1 폴백 유발. INT4V GPU HBM 저장 사실상 미사용. 실제 LLM 어텐션 분포에서 threshold 0.01~0.05 완화 탐색 필요.
2. **K/V 분리 구현 단순화**: put() 메서드에서 동일 텐서를 Key와 Value 양쪽으로 저장. CacheStore 인터페이스 단일-텐서 설계 제약. run_pipeline() 경로를 통한 K/V 독립 처리로 우회.
3. **CPU-only 환경 TTFT 한계**: write+read 합산 오버헤드 p50=1.9ms/레이어(Python CPU). GPU 어텐션 커널(50-200ms) 기준 무시 가능 수준 예상이나 실측 필요.
