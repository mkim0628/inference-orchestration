## 오늘 초점: Activity A+B (C 시너지)

### 신규 트렌드
- **ObjectCache (A-1)**: S3를 4번째 KV 저장 계층으로 활용하는 layerwise RDMA 아키텍처. break-even 공식(`hit_rate_breakeven = t_recompute / (t_recompute + t_s3)`)으로 S3 티어 활성화 결정.
- **Irminsul (B-1)**: MLA(Multi-head Latent Attention) 아키텍처에 최적화된 δ-rotation 위치 독립 캐싱(PIC). CDC(Content-Defined Chunking) + SHA-256 콘텐츠 해시 키.

### 주요 구현 컴포넌트
- `IrminsulMLASegmentCache` — MLA-native CDC 청킹 + δ-rotation k_r 보정 + SHA-256 content-hash 키
- `ArchitectureAwareNonContiguousRouter` — MLA/GQA/MHA 아키텍처 자동 감지 및 라우팅
- `CDCContentHashSegmentIDInterface` — HBM→DRAM→SSD→S3 4-계층 폭포식 조회 + 계층 승격
- `ObjectCacheS3TierRouter` — EMA + hysteresis 기반 S3 티어 활성화 게이팅
- `IrminsulObjectCachePipeline` — CDC→tier lookup→δ-rotation→attention input 엔드-투-엔드 파이프라인
- `MLATwoAxisCompressionCodec` — position-axis(포인터 중복제거, 무손실) × depth-axis(코사인 유사도 기반 레이어 공유) 2축 압축
