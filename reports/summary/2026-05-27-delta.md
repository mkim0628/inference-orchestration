## 새로운 패턴 확립

1. **segment_cache_side_only 정확도 계약**: write_to_cache가 primary attention kernel에 원본 KV를 반환하고 segment cache 경로에만 토큰 선택/잠재 저장을 적용. primary kernel rel_err = 0.0 구조적 보장.

2. **SegmentLatentPool DRAM LRU**: 퇴거된 KV 세그먼트의 latent state를 GPU VRAM이 아닌 DRAM(CPU 메모리)에 저장. GPU 메모리 비사용 + LRU 퇴거 확인.

3. **hard_hit / soft_hit / miss 3경로 라우팅**: IndexMemSoftHitSchedulerMixin이 block manager 연결 여부에 따라 soft_hit 분류. im_routing_stats API로 경로별 카운트 실시간 모니터링.

4. **pydantic frozen model 호환 CacheConfig 확장**: object.__setattr__ 방식으로 vLLM 0.21.0 pydantic 모델에 indexmem_budget_ratio, indexmem_beta, compression_method 필드 주입 확인.
