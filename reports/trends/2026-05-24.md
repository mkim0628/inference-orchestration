## Activity A — KV Cache-aware Scheduling / Orchestration

### 새로운 논문·구현체

#### 1. [DualPath: Breaking the Storage Bandwidth Bottleneck in Agentic LLM Inference](https://arxiv.org/abs/2602.21548)
- **출처**: arXiv 2602.21548 (2026-02-26, DeepSeek, Peking University, Tsinghua University — Wu Yongtong 외)
- **핵심 아이디어**: 에이전틱 멀티-턴 LLM 추론에서 KV 캐시 히트율이 95% 이상으로 증가하면서 연산보다 저장소-KV I/O가 병목이 됐다. 기존 P/D 분리 아키텍처에서 KV 캐시는 오직 "저장소→프리필 노드" 경로(single-path)로만 로드되어 프리필 노드의 스토리지 NIC가 대역폭 포화에 이르는 반면, 디코딩 노드의 스토리지 NIC는 유휴 상태로 낭비된다. DualPath는 이 비대칭성을 해결하기 위해 두 번째 경로 — **저장소→디코딩 노드→프리필 노드(RDMA)** — 를 개척한다. 핵심 설계: (1) **스토리지-to-디코딩 경로** — 디코딩 노드의 스토리지 NIC로 KV를 로드한 후 컴퓨트 네트워크(RDMA)를 통해 프리필 노드로 전달. 이 경로는 모델 실행 통신과 네트워크 혼잡을 공유하지 않으므로 간섭이 없음, (2) **글로벌 로드 밸런서** — 두 경로의 부하를 동적으로 균형 조정. DeepSeek V3.2 660B(MoE), 27B 축소 모델, Qwen2.5-32B(dense GQA)에서 검증됐으며 기존 추론 프레임워크 위에 약 5,000줄 코드로 구현됐다.
- **연구 목표와의 관련성**: high
- **주목할 점**: 오프라인 추론에서 최대 **1.87× 처리량 향상**, 온라인 서빙에서 SLO 위반 없이 평균 **1.96× 처리량 향상**. Activity A의 "멀티-노드 KV 라우팅" 및 "KV 전송 오버헤드 최소화" 목표에서 P/D 분리 환경의 스토리지 NIC 비대칭성이라는 새로운 병목을 규명하고 해결하는 최초의 논문이다. DualPath는 "컴퓨트 네트워크(RDMA)와 스토리지 네트워크를 분리 운용"한다는 점에서 Activity A의 "network-aware KV scheduling(InfiniBand/NVLink/RDMA)" 목표의 가장 구체적인 실현이다. Together AI CPD(이미 보고)가 "warm/cold/decode 노드 유형 분리"로 워크로드를 격리했다면, DualPath는 "스토리지 NIC 경로 이중화"로 I/O 대역폭 자체를 배가하는 보완적 방향이다. KVServe(이미 보고, 2605.13734)의 Bayesian 기반 압축이 "KV 전송 크기를 줄이는" 접근이라면, DualPath는 "전송 경로 자체를 병렬화하는" 접근으로 두 방법의 결합이 에이전틱 P/D 분리 환경에서 최대 대역폭 활용을 달성한다.

#### 2. [SideQuest: Model-Driven KV Cache Management for Long-Horizon Agentic Reasoning](https://arxiv.org/abs/2602.22603)
- **출처**: arXiv 2602.22603 (2026-02-26/27, 다수 저자)
- **핵심 아이디어**: 딥 리서치, 멀티-홉 RAG 같은 장기 에이전틱 태스크에서 컨텍스트가 외부 검색 토큰으로 지배되어 KV 캐시가 빠르게 증가한다. 기존 휴리스틱 KV 압축 방법들은 멀티-스텝 추론 모델에서 실패하는데, 이는 이 모델들이 상태를 장기간 유지해야 하는 긴 추론 체인을 생성하기 때문이다. SideQuest는 **추론 모델 자체를 KV 압축의 주체**로 활용한다는 독창적 패러다임을 제안한다. 핵심 설계: (1) **주 태스크와 병렬 보조 태스크** — KV 압축을 보조 태스크로 프레이밍해 메인 추론 컨텍스트의 오염 없이 압축 결정을 생성, (2) **모델-주도 토큰 효용 판단** — LRM(Large Reasoning Model) 자체가 컨텍스트의 토큰 효용성을 추론해 압축 여부를 결정, (3) **경량 훈련** — 단 215개 샘플로 압축 추론 능력 훈련 가능.
- **연구 목표와의 관련성**: high
- **주목할 점**: 에이전틱 태스크에서 피크 토큰 사용 **최대 65% 절감**을 휴리스틱 기반 KV 압축 방법 대비 정확도 손실 최소화로 달성. Activity A의 "에이전틱 KV 스케줄링"과 Activity C의 "정확도 보존 압축"을 교차하는 위치에 있다. CacheTTL(이미 보고)의 TTL 기반 KV 보존이 "KV를 얼마나 오래 유지할 것인가"를 결정한다면, SideQuest는 "현재 컨텍스트의 어떤 토큰이 장기적으로 유용한가"를 추론 모델 자체가 평가하는 상보적 방향이다. CONCUR(이미 보고)의 혼잡 기반 입장 제어 + ThunderAgent(이미 보고)의 LLM Program 정적 분석 + SideQuest의 모델-주도 토큰 효용 평가를 결합하면, 에이전틱 KV 관리의 "거시적 스케줄링(CONCUR/ThunderAgent) + 미시적 압축 결정(SideQuest)"의 완전한 계층 구조가 가능하다. TriAxialKV(이미 보고, 2605.17170)의 3축 혼합 정밀도 태깅이 에이전틱 KV의 역할 분류를 사전 정의된 카테고리로 처리한다면, SideQuest는 추론 모델이 태스크 컨텍스트에 맞는 압축 결정을 동적으로 생성하는 무-카테고리 접근이다.

## Activity B — Non-Contiguous KV Cache Reuse

### 새로운 논문·구현체

이번 기간(2026-05-17 ~ 2026-05-24) 관련성 high/medium의 신규 Activity B 항목이 발견되지 않았다. 비연속 KV 재사용 분야는 5주 연속 소강 상태이며, 직전 주까지 보고된 RelayCaching(2603.13289), ICaRus(2603.13281), QKVShare(2605.03884), KV-Fold(2605.12471), KVM(2605.09877), AdapShot(2605.03644), Louver(2605.06763), 2603.20218(CLC 실험 연구)가 현재 Activity B의 최전선이다.

**A→B 시너지 관점**: DualPath(Activity A 등재)의 저장소-to-디코딩 경로가 Activity B의 비연속 세그먼트 스토리지에 새로운 통합 기회를 제공한다. 비연속 세그먼트를 분산 스토리지에서 디코딩 노드를 경유해 프리필 노드로 전달하는 경로는 DualPath의 dual-path 프레임워크와 구조적으로 일치한다 — "비연속 세그먼트를 스토리지에서 읽을 때 decode 노드의 유휴 NIC를 활용해 프리필로 전달"하는 DualPath+비연속 재사용 통합 파이프라인이 가능하다.

**A→B 시너지 관점 2**: SideQuest(Activity A 등재)의 모델-주도 토큰 효용 평가를 Activity B에 적용하면, 비연속 세그먼트의 재사용 가능성을 어텐션 점수 휴리스틱 대신 추론 모델이 직접 판단하는 "모델-주도 비연속 세그먼트 가치 평가" 방향이 가능하다. 2603.20218(CLC 실험 연구, 이미 보고)이 "위치 독립 재사용의 정확도 한계를 실험으로 규명"했다면, SideQuest 스타일 모델-주도 평가가 "어떤 세그먼트를 위치 재인코딩 없이 직접 재사용할 수 있는가"를 모델이 직접 판단하는 새로운 경계 조건 정의 방법이 될 수 있다.

## Activity C — KV Cache Compression

### 새로운 논문·구현체

#### 1. [TriAttention: Efficient Long Reasoning with Trigonometric KV Compression](https://arxiv.org/abs/2604.04921)
- **출처**: arXiv 2604.04921 (2026-04-06, Weian Mao, Xi Lin, Wei Huang, Yuxin Xie, Tianfu Fu, Bohan Zhuang, Song Han, Yukang Chen — Zhejiang University, MIT CSAIL, NVIDIA; GitHub: github.com/WeianMao/triattention)
- **핵심 아이디어**: 기존 KV 캐시 압축 방법들이 최신 post-RoPE 쿼리의 어텐션 점수로 KV 중요도를 추정할 때, RoPE 적용 후 쿼리 벡터가 위치에 따라 회전해 대표 쿼리 수가 매우 적어져 추론(reasoning) 태스크에서 상위 키 선택이 불안정해지는 문제를 해결한다. TriAttention의 핵심 관찰: **pre-RoPE 공간에서 Q·K 벡터가 고정 비제로 중심 주변에 고도로 집중(Q/K concentration)되어 위치에 무관하게 안정적이다.** 이 집중성이 쿼리로 하여금 특정 거리의 키를 선호하게 만들며, 그 중심이 선호 거리를 삼각함수 급수로 결정한다. TriAttention은 Q 중심과 삼각함수 급수로 키의 중요도 차이를 거리 선호도에 기반해 평가하고, Q/K 노름을 부가 신호로 활용하며, Q/K 집중도 메트릭으로 두 신호를 자동 균형 조정한다. 상위 점수 키만 유지하는 KV 선택으로 메모리를 절감한다.
- **연구 목표와의 관련성**: high
- **주목할 점**: AIME25 32K 토큰 생성에서 동등 정확도(40.8%) 유지하면서 풀-어텐션 대비 **2.5× 처리량 또는 10.7× KV 메모리 절감** — 기존 최선 방법이 동일 효율에서 정확도가 절반에 불과한 것과 대비. GitHub 구현체 공개로 OpenClaw 모델을 메모리 제약 단일 소비자 GPU에서 실행 가능하게 했다. Activity C의 "KV 캐시 메모리 −30% 이상" + "압축 정확도 delta ±1% 이내" 목표를 추론(reasoning) 워크로드에서 10.7× 메모리 절감과 함께 풀-어텐션 동등 정확도로 초과 달성한다. NAtH(이미 보고, 2605.09490)가 추론 LLM의 CoT 토큰 KV를 DDR 오프로딩으로 보존한다면, TriAttention은 추론 생성 중 KV 자체의 크기를 삼각함수 중요도 평가로 줄이는 상보적 방향이다 — "TriAttention으로 추론 KV를 10.7× 압축 + NAtH DDR 오프로딩으로 압축 KV 보존"의 2단계 추론 LLM KV 절감 파이프라인이 가능하다. DapQ(이미 보고, 2603.11564)가 "위치 정보가 의미 정보보다 KV 중요도에 더 결정적"임을 발견했다면, TriAttention은 동일 통찰을 삼각함수 급수 이론으로 정형화해 위치 기반 거리 선호도를 수학적으로 계산하는 방법을 제공한다.

#### 2. [Fast KV Compaction via Attention Matching](https://arxiv.org/abs/2602.16284)
- **출처**: arXiv 2602.16284 (2026-02-18, Adam Zweiger, Xinghong Fu, Han Guo, Yoon Kim — MIT; GitHub: github.com/adamzweiger/compaction)
- **핵심 아이디어**: 기존 장문 컨텍스트 관리 방법인 (1) 토큰 공간 요약(summarization)은 손실이 크고, (2) 최근 Cartridges 스타일 잠재 공간 KV 압축은 엔드-투-엔드 최적화가 느리고 비싸다는 두 한계를 해결한다. **Attention Matching(AM)** 은 레퍼런스 쿼리 집합에 대해 각 KV 헤드별로 어텐션 출력과 어텐션 매스(attention mass)를 보존하는 소규모 콤팩트 K·V 쌍을 잠재 공간에서 직접 최적화하는 방법이다. 핵심 설계: (1) **두 가지 AM 목표 함수** — 어텐션 출력 매칭과 어텐션 매스 매칭으로 분리하여 서브 문제를 독립 해결, (2) **효율적 분해** — 일부 서브 문제는 닫힌 형태(closed-form)의 최소제곱 해가 존재해 반복 최적화 불필요, (3) **속도 우위** — Cartridges와 동등한 압축 품질을 수백 배 빠른 속도로 달성.
- **연구 목표와의 관련성**: high
- **주목할 점**: 일부 데이터셋에서 **50× 압축을 수 초 내에 품질 손실 최소화로 달성**; Cartridges 수준 압축비와 품질을 **2 오더(100×) 빠른 속도**로 달성. llama.cpp GitHub에서 "extreme VRAM savings"를 위한 구현 요청 이슈(#20037)가 개설돼 커뮤니티 관심도가 높다. Activity C의 "Effective Context Length 2× 이상" 목표를 잠재 공간 압축으로 50×까지 확장하는 가장 극단적인 방법이다. KVSculpt(이미 보고, 2603.27819)가 L-BFGS + 최소제곱 교대 최적화로 "증류" 패러다임을 KV 압축에 도입했다면, Attention Matching은 동일한 최소제곱 아이디어를 "헤드별 어텐션 출력 보존"이라는 더 명확한 목표 함수로 재구성해 닫힌 형태 해를 도출한다 — 두 방법의 알고리즘 비교가 Activity C 구현의 중요한 설계 선택이 된다. Activity B의 비연속 세그먼트 재사용에서 재사용 세그먼트를 Attention Matching으로 50× 콤팩트 KV로 압축한 후 재조합하면 비연속 세그먼트 캐시 용량이 대폭 확장된다.

#### 3. [CodeComp: Structural KV Cache Compression for Agentic Coding](https://arxiv.org/abs/2604.10235)
- **출처**: arXiv 2604.10235 (2026-04-11, The University of Hong Kong / LMSYS Org)
- **핵심 아이디어**: 에이전틱 코딩 태스크(fault localization, patch generation)에서 긴 코드베이스 처리 시 KV 캐시가 주 메모리 병목이 되지만, 기존 압축 방법들이 어텐션 신호만으로 토큰 중요도를 추정해 **구조적으로 핵심적인 토큰** — call site, 분기 조건, 할당문 등 — 을 체계적으로 제거하는 문제를 해결한다. CodeComp는 최초로 **Code Property Graph(CPG) 프라이어**를 KV 퇴거 정책에 통합하는 훈련-프리 프레임워크이다. Joern 정적 분석 도구로 CPG를 추출해 코드 구조적 중요도를 토큰별로 계산하고, 어텐션 점수와 구조적 중요도를 결합한 하이브리드 퇴거 기준으로 코드 이해에 필수적인 토큰을 보존한다.
- **연구 목표와의 관련성**: high
- **주목할 점**: 에이전틱 코딩 특화 KV 압축에서 기존 어텐션-전용 방법 대비 fault localization과 patch generation 정확도 향상. Activity C의 "정확도 보존(accuracy-preserving)" 압축 제약을 코드 도메인에서 CPG 구조 프라이어로 보장하는 최초의 방법이다. SP-KV(이미 보고, 2605.14037)의 write-time KV 기록 결정이 도메인-무관 효용 예측기를 훈련한다면, CodeComp는 정적 분석 프라이어(CPG)를 훈련 없이 퇴거 기준에 직접 통합해 코드 도메인의 도메인-특화 지식을 활용한다. TriAxialKV(이미 보고, 2605.17170)가 에이전틱 워크로드에서 "의미적 역할" 축으로 시스템 지시어·도구 호출·관찰을 분류했다면, CodeComp는 코드 에이전트 특화 구조적 역할(call site·분기·할당)을 CPG로 분류한다 — 두 방법의 결합이 코드 에이전트의 "에이전틱 역할(TriAxialKV) × 코드 구조(CodeComp)" 이중 분류 KV 압축을 가능하게 한다.

## Activity 간 시너지 포인트

**A + C (DualPath + TriAttention + SideQuest)**
DualPath(A)가 스토리지→decode→prefill RDMA 이중 경로로 KV I/O 대역폭을 배가하고, TriAttention(C)이 추론 KV를 10.7× 압축해 전송 크기를 줄이며, SideQuest(A/C 경계)가 추론 모델 자체로 어떤 토큰 KV를 전송할지 결정한다. 세 방법의 조합이 에이전틱 추론 서비스에서 "전송 경로 이중화(DualPath) + KV 크기 극소화(TriAttention) + 전송 대상 모델-주도 선택(SideQuest)"의 3단 KV 전송 최적화를 실현한다.

**A + B (DualPath + 비연속 세그먼트)**
DualPath의 스토리지→decode→prefill 이중 경로가 Activity B의 분산 스토리지에 보관된 비연속 세그먼트를 decode 노드의 유휴 NIC를 통해 효율적으로 prefill로 전달하는 새로운 데이터 흐름을 제공한다. Louver(B)의 제로 거짓 음성 세그먼트 검색 + AdapShot(B)의 위치 재인코딩 + DualPath의 이중 경로 전송 + KV-RM(이미 보고, A)의 비연속 블록 합체 전송을 통합하면 에이전틱 환경의 완전한 비연속 세그먼트 재사용 전송 스택이 된다.

**B + C (Attention Matching + 비연속 세그먼트)**
Attention Matching(2602.16284)의 50× 잠재 공간 KV 압축이 Activity B의 비연속 세그먼트 캐시에 적용되면, 동일 메모리 예산에서 유지 가능한 비연속 세그먼트 수가 대폭 증가한다. 각 세그먼트를 Attention Matching으로 압축 저장하고 재사용 시 레퍼런스 쿼리로 복원하는 "압축 비연속 세그먼트 캐시"가 Activity B+C의 자연스러운 통합 방향이다. AdapShot(B)의 RoPE 위치 재인코딩과 결합하면 "압축 세그먼트 복원 → 위치 재인코딩 → 어텐션 연산"의 3단계 재사용 파이프라인이 구성된다.

**A + B + C (3-Way: DualPath + 비연속 세그먼트 + TriAttention + Attention Matching)**
에이전틱 추론 워크로드에서의 통합 파이프라인: SideQuest(A)가 추론 모델로 토큰 효용 평가 → 비연속 세그먼트 선택(B) → TriAttention(C)으로 선택된 세그먼트 10.7× 압축 → Attention Matching(C)으로 잠재 공간 50× 추가 압축 → DualPath(A) 이중 경로로 압축 세그먼트 전송 → AdapShot(B)으로 위치 재인코딩 후 재사용. 세 Activity가 추론 LLM 에이전틱 서비스에서 KV 메모리·전송·관리를 전방위 최적화하는 완전한 스택이다.
