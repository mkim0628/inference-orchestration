## Activity A — KV Cache-aware Scheduling / Orchestration

### 새로운 논문·구현체

#### 1. [Randomization Boosts KV Caching, Learning Balances Query Load: A Joint Perspective](https://arxiv.org/abs/2601.18999)
- **출처**: arXiv 2601.18999 (2026-01-26 제출, ICLR 2026 게재 — Fangzhou Wu 외 2인)
- **핵심 아이디어**: KV 캐싱의 효율성이 퇴거 정책(eviction policy)에 민감하며, 특히 다중 LLM 서빙 환경에서 로드 밸런싱(워커 간 요청 균등 분배)과 캐시 히트율 최대화(동일 인스턴스로 동일 프롬프트 라우팅)가 구조적으로 상충함을 분석한다. 이 논문은 KV 캐시 퇴거와 쿼리 라우팅을 **최초의 통합 수학 모델**로 정형화해, 기존 방법들의 이론적 한계를 규명하고 (1) **확률적으로 경쟁적인 무작위 KV 캐시 퇴거(provably competitive randomized eviction)** + (2) **학습 기반 쿼리 라우팅(learning-based query routing)**을 통합하는 원칙적 알고리즘을 도출한다. 무작위 퇴거가 LRU 대비 동적 요청 도착에서 우월하다는 이론적 보장을 제공하며, 학습 기반 라우팅이 진화하는 쿼리 패턴에 적응해 캐시 히트율과 로드 밸런싱을 동시에 달성한다.
- **연구 목표와의 관련성**: high
- **주목할 점**: 4개 벤치마크와 3가지 prefix-sharing 설정에서 추론 효율성 "실질적 향상" 및 종단간 지연 "주목할 수준의 감소" 달성. **ICLR 2026 게재 논문**으로 학술 검증 완료. DualMap(이미 보고, 2602.06502)이 이중 해시 매핑으로 캐시 어피니티와 로드밸런싱의 실용적 근사를 달성했다면, 이 논문은 동일 문제를 최초의 통합 수학 모델로 정형화해 DualMap 설계의 이론적 기반을 제공한다. Activity A의 "cache-locality scheduling"과 "multi-node KV routing" 목표에서 알고리즘 선택의 이론적 근거를 수립하는 기초 논문이다.

#### 2. [TokenDance: Scaling Multi-Agent LLM Serving via Collective KV Cache Sharing](https://arxiv.org/abs/2604.03143)
- **출처**: arXiv 2604.03143 (2026-04-03, Peking University, Shanghai Jiao Tong University)
- **핵심 아이디어**: 멀티-에이전트 LLM 애플리케이션은 동기화된 라운드 방식으로 실행된다 — 중앙 스케줄러가 모든 에이전트 출력을 수집(gather)해 결합된 컨텍스트를 재배포한다. 이 **All-Gather 통신 패턴**이 거대한 KV 캐시 중복을 만들지만, 기존 재사용 방법이 이를 활용하지 못한다. TokenDance는 두 가지 핵심 기술로 이 중복을 제거한다: (1) **KV Collector** — 전체 라운드에 걸쳐 KV 캐시 재사용을 한 번의 집합적 단계로 수행해, 에이전트 수에 관계없이 공유 블록의 재사용 비용을 1회만 지불, (2) **Diff-Aware Storage** — 형제 캐시를 단일 마스터 복사본에 대한 블록-스파스 차이(diff)로 인코딩해 11~17× 압축 달성.
- **연구 목표와의 관련성**: high
- **주목할 점**: GenerativeAgents·AgentSociety 벤치마크에서 SLO 조건 하에 vLLM(prefix caching) 대비 **2.7× 더 많은 동시 에이전트** 지원, 에이전트당 KV 캐시 스토리지 최대 **17.5× 감소**, per-request 위치-독립 캐싱 대비 **1.9× 프리필 속도 향상**. RelayCaching(이미 보고, 2603.13289)이 디코딩→프리필 KV 직접 재사용으로 에이전트 간 순차적 KV 전달을 다룬다면, TokenDance는 동기화 라운드의 집합적 KV 공유라는 직교적 에이전틱 패턴을 다룬다. Activity A의 "멀티-노드 KV 라우팅"과 "캐시 퇴거율 최소화" 목표에서 멀티-에이전트 서빙 환경의 새로운 최적화 기회를 제시한다. PolyKV(별도 검색 결과, 2604.24971)의 공유 압축 풀 방식과 TokenDance의 Diff-Aware Storage가 상보적이다 — PolyKV가 "단일 공유 풀에서 압축된 KV를 N 에이전트에 주입"한다면, TokenDance는 "All-Gather 패턴의 차이만 저장"하는 구조적 중복 제거 방식이다.

## Activity B — Non-Contiguous KV Cache Reuse

### 새로운 논문·구현체

#### 1. [KV Packet: Recomputation-Free Context-Independent KV Caching for LLMs](https://arxiv.org/abs/2604.13226)
- **출처**: arXiv 2604.13226 (2026-04-14 제출, 04-17 갱신 — Chuangtao Chen 외, TUM 관련; GitHub: github.com/ChuangtaoChen-TUM/KVPacket)
- **핵심 아이디어**: 표준 KV 캐시는 전체 선행 컨텍스트와 절대 위치 인덱스 모두에 의존하기 때문에, 새 컨텍스트에서 캐시된 문서를 재사용하려면 KV 상태를 재계산해야 한다. CacheBlend, EPIC, SAM-KV 같은 기존 솔루션은 토큰의 일부만 선택적으로 재계산하지만 여전히 무시할 수 없는 FLOPs와 TTFT 지연이 발생한다. KV Packet은 캐시된 문서를 **불변 "패킷"**으로 취급하고 경량 훈련 가능한 소프트-토큰 어댑터(trainable soft-token adapters)로 감싸서 컨텍스트 불연속성을 자기지도 증류(self-supervised distillation)로 보완한다. 새로운 컨텍스트에서도 재계산 없이 패킷을 직접 삽입하는 구조다.
- **연구 목표와의 관련성**: high
- **주목할 점**: Llama-3.1·Qwen2.5 모델 실험에서 재계산 기반 베이스라인 대비 **재계산 FLOPs 제로** + 더 낮은 TTFT 달성, F1 점수는 베이스라인과 동등 수준 유지. Activity B의 핵심 질문 — "접두사 불일치에도 임의 위치 KV 세그먼트를 재사용할 수 있는가" — 에 "재계산 없이 가능하다"는 답을 제시하는 논문이다. CacheBlend(기존 보고)가 "일부 토큰을 재계산해 크로스-어텐션을 복원"한다면, KV Packet은 "소프트-토큰 어댑터 증류로 재계산 자체를 제거"하는 근본적으로 다른 접근이다. AdapShot(이미 보고, 2605.03644)의 RoPE 회전 기반 위치 재인코딩이 "위치 불일치를 회전으로 수정"한다면, KV Packet은 "어댑터 증류로 컨텍스트 불연속성 자체를 흡수"한다 — 두 방법이 서로 다른 불연속성의 원인(위치 인코딩 vs 컨텍스트 의존성)을 분리해 처리하는 상보적 조합이 가능하다. GitHub 구현체 공개로 Activity B의 src/cache/segmented.py에 KVPacket 스타일 어댑터 레이어를 통합하는 단기 구현 경로가 열렸다.

## Activity C — KV Cache Compression

### 새로운 논문·구현체

#### 1. [VeriCache: Turning Lossy KV Cache into Lossless LLM Inference](https://arxiv.org/abs/2605.17613)
- **출처**: arXiv 2605.17613 (2026-05-17, University of Chicago, Tensormesh Inc., Samsung Semiconductor, Microsoft Research)
- **핵심 아이디어**: 기존 KV 캐시 압축 방법들은 본질적으로 손실이 있어, 짧은 출력에서는 정확도 저하가 미미하더라도 더 많은 토큰을 디코딩할수록 전체 KV 캐시 출력과의 차이가 누적되어 코드 생성·도구 호출 같은 정밀한 태스크에서 **파국적 실패**가 발생하는 문제를 다룬다. VeriCache는 **투기적 실행(speculative execution)** 패러다임을 KV 압축에 처음으로 적용한다: (1) **압축 KV 캐시로 드래프트 토큰 생성** — 고속 압축 캐시를 사용해 여러 토큰을 병렬 드래프트, (2) **전체 KV 캐시로 검증** — 페이지드 스왑을 통해 전체 FP16 KV 캐시를 HBM으로 가져와 드래프트 토큰을 검증, (3) **병렬화 가능한 핵심 통찰** — 압축 KV 디코딩은 HBM 대역폭 바운드이고 전체 KV 스왑은 PCIe/네트워크 바운드이므로 두 작업을 병렬로 실행 가능.
- **연구 목표와의 관련성**: high
- **주목할 점**: 전체 KV 캐시 디코딩과 **동일한 출력을 수학적으로 보장**하면서 다양한 KV 압축 알고리즘의 높은 디코딩 처리량을 대부분 보존 — "손실 없는 KV 압축 추론"을 최초로 달성. Activity C의 **"압축 정확도 delta ±1% 이내"** 제약이 이 논문에서는 ±0% (완전 동일 출력)로 달성된다 — Runtime-Certified(이미 보고, 2605.20868)가 헤드·스텝별 런타임 오류 경계로 확률적 보장을 제공한다면, VeriCache는 전체 KV 검증으로 결정론적(deterministic) 보장을 제공하는 더 강한 보장 방식이다. 코드 생성·도구 호출처럼 출력 정확성이 중요한 에이전틱 태스크에서 특히 유용하다. 압축 드래프트와 전체 KV 검증의 병렬화가 가능한 이유("one is HBM-bandwidth-bound, the other is PCIe/network-bound")는 Activity A의 P/D 분리 환경에서 압축 KV를 프리필 노드에서 디코드 노드로 스트리밍 전송하면서 디코드 노드가 동시에 이전 드래프트를 검증하는 파이프라인 설계에도 직접 적용 가능하다.

#### 2. [Predictive Multi-Tier Memory Management for KV Cache in Large-Scale GPU Inference](https://arxiv.org/abs/2604.26968)
- **출처**: arXiv 2604.26968 (2026-04-26, 복수 저자 — 64-GPU H100 클러스터 기반 분석)
- **핵심 아이디어**: 대규모 GPU 추론에서 세 가지 비효율을 동시 해결하는 통합 KV 캐시 메모리 관리 프레임워크를 제안한다: (1) **아키텍처 변형 인식 크기 조정 엔진** — MLA 포함 모든 어텐션 아키텍처의 정확한 KV 메모리 요구량을 계산해 최대 7.4× 더 높은 배치 크기를 지원(기존 범용 프레임워크의 최대 57× 메모리 과다 프로비저닝 해결), (2) **Bayesian 재사용 예측** — 16가지 (블록 유형, 전환 유형) 쌍에 대한 Beta conjugate prior로 70~84% 캐시 히트율 + 1.4~2.1× 예측 TTFT 절감, (3) **RoPE-인식 헤드-단위 퇴거** — EMA 기반 어텐션 헤드별 중요도 추적 + 위치 인코딩 지역성 활용 프리페치로 LRU 대비 25% 미스율 감소.
- **연구 목표와의 관련성**: high
- **주목할 점**: 64-GPU H100 클러스터 분석에서 TensorRT-LLM 대비 **2.0× 처리량** + 30% 비용 절감, FlexGen 대비 **6.4× 처리량** + 11× 낮은 TTFT P99. Kareto(이미 보고, 2603.08739)가 Pareto 최적화로 스토리지 구성을 다목적 최적화했다면, 이 논문은 Bayesian 재사용 예측 + 아키텍처-인식 크기 조정 + RoPE-인식 헤드-단위 퇴거라는 세 요소를 통합해 예측적(predictive) 접근으로 한 단계 더 나아간다. Activity C의 "KV 캐시 메모리 −30% 이상" + "캐시 퇴거율 최소화" 목표에서 아키텍처 다양성(MLA, MHA, GQA)을 모두 처리하는 범용적 정확 크기 조정이 기존 방법들의 맹점이었음을 규명한다. DapQ(이미 보고, 2603.11564)가 위치 정보가 KV 중요도에 결정적임을 발견했다면, 이 논문의 RoPE-인식 헤드 퇴거가 동일 통찰을 퇴거-프리페치 파이프라인에 구현한 최초의 시스템 레벨 사례다.

#### 3. [Stochastic KV Routing: Enabling Adaptive Depth-Wise Cache Sharing](https://arxiv.org/abs/2604.22782)
- **출처**: arXiv 2604.22782 (2026-04-03, Anastasiia Filippova, David Grangier, Marco Cuturi, João Monteiro — Apple Machine Learning Research)
- **핵심 아이디어**: 기존 KV 캐시 감소 연구가 시간 축(토큰 퇴거·양자화·압축)에 집중하는 반면, **깊이(depth) 축** — 레이어 간 KV 캐시 공유 — 는 상대적으로 미탐구 영역이다. 이 논문은 학습 중 레이어가 자신의 KV 상태 또는 이전 레이어의 KV 상태 중 무작위로 선택해 어텐션하는 "무작위 크로스-레이어 어텐션(random cross-layer attention)" 학습 방식을 제안한다. 이 확률적 학습이 모델을 배포 시 미지의 하드웨어 제약에 대한 다양한 깊이 방향 캐시 공유 전략에 강건하게 만든다. 사전훈련 또는 파인튜닝 단계에서 적용 가능하며, 다양한 모델 패밀리에서 깊이 방향 캐시 공유를 가능하게 한다.
- **연구 목표와의 관련성**: high
- **주목할 점**: 사전훈련 또는 파인튜닝으로 다양한 모델 패밀리에서 시간 축 압축과 **직교적**으로 깊이 축 KV 메모리 절감 달성. Apple Machine Learning Research 발표. 시간 축(토큰 퇴거, 양자화) + 공간 축(비연속 세그먼트) + 깊이 축(이 논문)의 3차원 KV 캐시 최적화 공간이 완전히 탐색되기 시작했다. LRKV(이미 보고, 2601.11471)가 "레이어당 공유 풀-랭크 기저 + 헤드별 저랭크 잔차"라는 훈련-시간 아키텍처 방향으로 깊이 축을 다뤘다면, Stochastic KV Routing은 "무작위 크로스-레이어 어텐션 학습"으로 배포 시 다양한 공유 정책을 허용하는 더 유연한 방향을 제시한다. Activity C의 vLLM 이식(6단계)에서 SpecAttn(이미 보고)의 시간-축 희소화 + Stochastic KV Routing의 깊이-축 공유 + TriAttention(이미 보고)의 삼각함수 중요도 평가를 3축 통합 KV 절감 파이프라인으로 구성하면 Activity C 목표의 최대 달성이 가능하다.

## Activity 간 시너지 포인트

**A + C (TokenDance + VeriCache)**
TokenDance가 멀티-에이전트 All-Gather KV를 집합적으로 공유(17.5× 스토리지 절감)한 후, 공유된 압축 KV를 VeriCache로 전체 KV 검증하면 "집합적 공유(A) → 압축 KV 드래프팅(C) → 전체 KV 검증(C)"의 손실 없는 멀티-에이전트 KV 공유 파이프라인이 가능하다. 에이전틱 코드 생성·도구 호출에서 KV 메모리를 집합적으로 줄이면서도 출력 정확성을 완전히 보장하는 조합이다.

**A + B (TokenDance + KV Packet)**
TokenDance의 All-Gather KV 집합적 공유가 에이전트 간 비연속 KV 세그먼트의 Diff-Aware Storage(블록-스파스 차이)를 만들고, KV Packet의 소프트-토큰 어댑터가 이 비연속 세그먼트들을 재계산 없이 각 에이전트 컨텍스트에 삽입하는 파이프라인이 가능하다. "TokenDance Diff-Aware 세그먼트 저장(A) → KV Packet 어댑터 기반 재계산-프리 삽입(B)"의 에이전틱 비연속 세그먼트 재사용 스택이다.

**B + C (KV Packet + Stochastic KV Routing + Predictive Multi-Tier)**
KV Packet의 컨텍스트-독립 패킷을 Stochastic KV Routing의 크로스-레이어 공유로 레이어 간 중복을 줄이고, Predictive Multi-Tier의 Bayesian 예측 기반 3-티어 배치로 패킷의 히트 예측에 따라 HBM/DRAM/SSD 계층에 최적 배치하면, 비연속 세그먼트 캐시의 3축(공간·깊이·계층) 최적화가 달성된다.

**A + B + C (3-Way: Predictive Multi-Tier + KV Packet + VeriCache + TokenDance)**
에이전틱 멀티-에이전트 추론에서의 통합 파이프라인: TokenDance(A)가 All-Gather KV를 집합적으로 공유해 17.5× 중복 제거 → KV Packet(B)이 소프트-토큰 어댑터로 재계산 없이 비연속 세그먼트 삽입 → Stochastic KV Routing(C)이 깊이 방향으로 레이어 간 KV 공유해 추가 절감 → Predictive Multi-Tier(C/A)가 Bayesian 히트 예측 + RoPE-인식 퇴거로 3-티어 배치 최적화 → VeriCache(C)가 압축 KV로 빠르게 드래프트하고 전체 KV로 결정론적 검증. 세 Activity가 멀티-에이전트 에이전틱 LLM 서빙에서 "공간·깊이·계층·보장" 네 차원의 KV 최적화를 동시에 달성하는 완전한 스택이다.
