## 미해결 이슈

1. **TTFT 오버헤드 GPU 실측 미수행**: CPU-only 환경에서 write+read 합산 오버헤드 p50=1.9ms/레이어로 측정되었으나, 이는 GPU 커널 없는 환경의 Python CPU 오버헤드다. 실제 GPU 환경에서는 GPU 어텐션 커널(50-200ms)에 비해 무시 가능 수준으로 예상되나 실측 필요.

2. **멀티-GPU TP 환경 미검증**: CLCPositionalBiasGatedKVCacheManagerMixin의 build_clc_noncontiguous_block_table()은 TP rank 0에서 호출 후 broadcast 필요. 실제 멀티-GPU 환경에서 블록 테이블 일관성 실측 미수행.

3. **이전 사이클 smoke test 일부 실패**: 2026-05-22(DapQPositionAwareEvictionAttentionHook write_to_cache 인자 오류), 2026-05-16(NAtHDDR _attn_score_ema 오류) 등 이전 사이클 컴포넌트의 backward compat 실패. 현재 사이클(2026-05-23) 컴포넌트와 무관하나 backward compat 저하는 추적 필요.

4. **error_threshold 보수성**: 현재 0.005 설정으로 대부분 요청이 Level 1 폴백. 실제 워크로드에서 threshold 완화(0.01-0.05) 탐색 필요.
