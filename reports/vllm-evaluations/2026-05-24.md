## 미해결 이슈

없음. 모든 필수 항목(Activity C Perplexity/태스크 정확도, Activity A 스케줄링 오버헤드)이 충족되었다.

경미한 관찰 사항:
1. **이전 사이클 backward compat 실패 51건**: 2026-05-13, 2026-05-14, 2026-05-19 사이클 구현체가 후속 사이클에서 교체되어 해당 테스트가 ImportError로 실패. 기능적 문제가 아니나 smoke test 파일이 누적되면서 이전 구현을 요구하는 테스트도 그대로 남아있어 전체 pass 수 감소. backward compat 보존 정책 강화 고려.
2. **install.sh 업데이트 필요**: install.sh는 2026-05-16 사이클 기준 컴포넌트를 검증하도록 되어 있어 2026-05-24 신규 컴포넌트(TriAttentionPreRoPEKVSelectorHook, AttentionMatchingClosedFormHook, DualPathNICSchedulerMixin)가 명시적으로 포함되지 않음. 기능 검증은 가능하나 install.sh 자체가 오래된 상태.
3. **attention output 측정 일관성**: 두 가지 accuracy 측정 방법(token selection error vs. attention output with full/selected KV)이 혼용될 수 있음. vLLM 이식에서는 primary path가 항상 원본 KV를 사용하므로 primary path error = 0이 보장됨. 이를 Report에 명확히 기술하는 것이 권장됨.
