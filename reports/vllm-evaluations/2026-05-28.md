## 미해결 이슈

1. **RDMA 원격 히트율 30% 목표 미달**: pegaflow_peer_nodes.yaml이 빈 리스트여서 단일 노드 환경에서 rdma_remote_hit=0. Report ①과 동일한 구조적 환경 제약. RDMA 경로 자체는 코드 경로로 검증됨.
2. **Throughput/TTFT p50 실측값 null**: GPU 미탑재 환경에서 실제 LLM 추론 엔진 연동 없이 tokens/sec, TTFT p50/p99 수치 측정 불가. 기능 경로 및 오버헤드 측정으로 대체.
3. **TTFT p50 증가 측정 한계**: 실제 vLLM 추론 워크로드 없이 스케줄러 오버헤드만 측정 가능. 실제 서비스 환경에서는 추가 측정 필요.
